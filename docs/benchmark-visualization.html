RIID — benchmark scenarios: image pull and import time

Four independent tests: cold cache on one image, thirty images in sequence, warmup before a concurrent load, and how long each parallel import took. Values are embedded in this page. RIID is measured via the daemon API; Podman uses the native CLI on the same machine where applicable. Image names come from a public set of popular Docker Hub repositories. Hardware, network, and registry conditions affect absolute numbers; the charts are meant for relative comparison between approaches.

Scenario A — five cold-cache runs, one small image

The cache is cleared before each measurement; only the download time of the same image is timed, five runs in a row. Bars show the sum of those five readings (lower is faster overall). RIID (daemon request) vs direct podman pull on a local machine and in Yandex Cloud (separate run).

Scenario B1 — thirty images, strictly sequential

One run: first each of 30 images is pulled through RIID with timing, then a separate phase times podman pull over the same list (Podman caches are reset once for its phase per the test harness). Horizontal axis: milliseconds for one image; two series side by side. For some images the saved log has no Podman measurement—the chart shows missing Podman bars (RIID only).

Scenario C — warmup: fifteen smallest images by published size

Step before a concurrent-load test: for fifteen images in ascending order of published size, one RIID pull is timed. Horizontal axis: image size in bytes (log scale: sub‑kilobyte to tens of MiB do not fit on a linear axis). Vertical axis: pull time in milliseconds for that warmup run.

Scenario B2 — parallel pulls: when import finished and how long it ran

Several images are fetched and imported concurrently; each point is one finished engine import step (engine.import). Horizontal axis: seconds after the first such event in the saved excerpt (not absolute test start time). Vertical axis: how many minutes that import took for that image. Tooltips also show milliseconds from the trace.
